## Governing source

[Righting Software](<Righting Software.pdf>), Juval Löwy, governs The Method. Appendix C, printed pp. 425–430, is the adopted design standard. Use printed page numbers and the [source-authority record](../governance/source-authority.md) for edition, file identity, and source-resolution decisions.

Local document links resolve inside this repository. Supplementary web resources remain permitted.

# Sources and bibliography

## Source availability

The owner removed the reference directory on 2026-11-08. This repository does not distribute the source PDFs or the saved requirements article. Obtain authorized access to the cited edition before verifying a source-dependent rule. A retailer listing identifies a book; it does not supply the book text or prove that a passage was reviewed.

The Method's source authority and adopted rules remain unchanged. Use printed page numbers, headings, and source item identifiers. Historical file hashes and PDF page offsets describe the copies used for earlier reviews, not a file now supplied by this repository.

## Governing book

[Righting Software: A Method for System and Project Design](https://www.amazon.com/dp/0136524036), Juval Löwy, Addison-Wesley Professional, copyright 2020, ISBN 9780136524038. Appendix C, printed pp. 425–430, is the adopted design standard. See [source authority](governance/source-authority.md) and [review scope](research/source-review.md).
